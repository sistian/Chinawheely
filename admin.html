后台使用说明

总览：登录后顶部六卡 = 今日线索 / 今日订单 / 待确认 / 待核销 / 未收金 / 近7天会话。

线索 Tab：contact / booking 表单产生的咨询。点行开抽屉：改状态、评级、备注，一键 WhatsApp / 邮件 / 复制。CSV 可导出。

订单 Tab：三步预订表单产生的正式订单（CW- 开头参考号）。筛选支持服务状态 / 支付状态 / 日期 / 关键词。抽屉里「快捷动作」可一键流转状态或标记已付；也可手动改出发日期时间、备注。金额为人民币，含定金口径。

数据 Tab：自建埋点（不上报 PII）。今日漏斗 = 浏览→开始预订→提交订单→询盘；Top 城市/页面来自最近事件。

报价 Tab：331 城报价速查，与线上报价引擎同源（pricing/pricing.json）。接送机/城际同价（含 35km+60min），包车 5 档时长。城际按出发城市计价。超程按 perKm、超时按 perMin（30 分钟计费块）。

安全：会话仅存于当前标签页（关闭即失效）；右上角可改密码。若 401 会自动退回登录页。
